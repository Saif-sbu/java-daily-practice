# Student Management System

A Java command-line application for managing undergraduate and graduate student records.

## Features
- Add undergraduate and graduate students
- Validate student scores
- Generate student reports
- Calculate average scores
- Find highest score
- Handle invalid scores and empty student lists

## Concepts Used
- Object-oriented programming
- Abstraction
- Inheritance
- Interfaces
- Method overriding
- Custom exceptions
- Dynamic arrays
- Recursion

## Technologies
Java
